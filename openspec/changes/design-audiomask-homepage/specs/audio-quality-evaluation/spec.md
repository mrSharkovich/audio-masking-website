# Spec Delta

## Purpose

Определить ручную оценку качества аудио по PESQ и ViSQOL с прозрачными состояниями и независимостью от прослушивания и скачивания результата.

## ADDED Requirements

### Requirement: Проверка оценки без вычислительного backend
В первом этапе интерфейс оценки SHALL приниматься с тестовым адаптером без реальных PESQ/ViSQOL. Примеры значений SHALL иметь явную маркировку тестовых данных и не считаться вычисленными метриками. Реальные вычисления SHALL относиться к отдельной будущей спецификации.

#### Scenario: Тестовые состояния метрик
- **WHEN** тестовый адаптер возвращает заранее заданный результат, ошибку или недоступность
- **THEN** интерфейс показывает соответствующее состояние без вычисления метрик и выдачи примеров за реальные оценки

### Requirement: Только явный запрос оценки
Экран результата SHALL содержать кнопку «Оценить качество». PESQ и ViSQOL SHALL запрашиваться только по этому действию, для явно обозначенной согласованной пары записей и условий расчёта.

#### Scenario: Результат маскирования открыт
- **WHEN** пользователь получает обработанное аудио
- **THEN** метрики находятся в состоянии «не запрошено», вычисления не запускаются

#### Scenario: Запрос оценки
- **WHEN** пользователь нажимает «Оценить качество» и контракт сравнения согласован
- **THEN** интерфейс запрашивает PESQ и ViSQOL для обозначенной пары, показывает ожидание и предотвращает дублирование запроса

#### Scenario: Контракт сравнения не определён
- **WHEN** пара или условия расчёта ещё не согласованы
- **THEN** оценка явно недоступна с пояснением, интерфейс не выбирает преобразования и сравниваемые записи самостоятельно

### Requirement: Независимые состояния метрик
Каждая метрика SHALL иметь состояния ожидания запроса, загрузки, результата, ошибки и недоступности. В реальной интеграции числа SHALL поступать только из ответа сервиса; в первом этапе допустимы только явно помеченные тестовые примеры. Отсутствие значения SHALL не подменяться нулём или приблизительной оценкой.

#### Scenario: Частичный результат
- **WHEN** PESQ вернул значение, а ViSQOL недоступен
- **THEN** показаны значение PESQ из ответа адаптера и отдельное сообщение о недоступности ViSQOL; в первом этапе значение явно помечено как тестовое

#### Scenario: Ошибка вычисления
- **WHEN** вычисление метрики завершается ошибкой
- **THEN** показана понятная ошибка и возможность повторного явного запроса при доступности сервиса; плееры и скачивание остаются доступны

#### Scenario: Смена рабочего результата
- **WHEN** получен новый результат маскирования, пока ожидается ответ для старого
- **THEN** старый ответ не отображается как оценка новой записи
